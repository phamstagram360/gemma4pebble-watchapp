# AI Assistant for Pebble – Watch App

Companion watchapp for Gemma4Pebble.

- Press the **middle button** → Pebble mic opens
- Speak your question → sent to iPhone
- iPhone runs Gemma locally → reply appears on watch

Same UUID as Bobby (`1d272bb4-cf00-4e3e-a7f3-7394309e0341`) — no iOS changes needed.

## Install

1. Push this folder to a GitHub repo (any name, public or private)
2. Go to **Actions** → select the run → download `AI-Assistant-for-Pebble` artifact
3. Unzip → double-click `AI-Assistant-for-Pebble.pbw` → Rebble opens and installs it
